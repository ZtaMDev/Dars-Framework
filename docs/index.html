Dars Framework Dynamic Application Rendering System is a modern Python framework for web and desktop apps development. Dars is designed to make web and desktop apps development simple, fast, and enjoyable. With an intuitive API and powerful features, you can build modern web and desktop apps in record time using Python.
pip install dars framework

Features Everything you need to build amazing applications
Fast Development Build applications quickly with our intuitive API and pre-built components, or creating your own custom components.
Multiplatform Deploy your apps on web and desktop with the same codebase changing only a single configuration.
High Performance Optimized rendering and efficient resource management for smooth experiences.
Easy to Use Declarative syntax and comprehensive documentation to get you started fast with an built in state managment for your UI components.
Modern UI Beautiful, responsive components that follow modern design principles with standard CSS styles.
Extensible Flexible and easy to use for various types of applications.
How It Works Get started with Dars in three simple steps
Install Install Dars with a simple pip install dars-framework and start building immediately.
Develop Use the intuitive API to create routes, components, and pages with minimal code.
Deploy Deploy your application in the test built-in server or your preferred hosting provider. Or export it to desktop as a native app.
